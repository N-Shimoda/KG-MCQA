# kgraph
## How to install `kgraph`
```Bash
pip install kgraph
```

## Files
- `main.py`
- `funcs.py`
- `subnodes.py` : Find the largest common subgraph nodes from 2 knowledge graphs.
- `utils.py`

## Reference
`kgraph` package is based on the following Medium article:   
> [Fabio Chiusano, *"Building a Knowledge Base from Texts: a Full Practical Example"* (May 2022)](https://medium.com/nlplanet/building-a-knowledge-base-from-texts-a-full-practical-example-8dbbffb912fa)
